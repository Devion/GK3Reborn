GK3Reborn

A modern engine for Gabriel Knight 3: Blood of the Sacred, Blood of the Damned. This installer places GK3Reborn.app in your Applications folder.

It contains no game data. GK3Reborn plays the game from an installation you already own, which it reads and never modifies. After installing, copy the eight archives from your installation's Data folder into:

~/Library/Application Support/GK3Reborn/Data

  • ambient.brn, common.brn, core.brn, day1.brn
  • day123.brn, day2.brn, day23.brn, day3.brn

Nothing else from the original is needed. The same folder is where the game keeps your saved games and settings, and where a downloaded .rebarn content pack goes.

Requires Apple silicon and macOS 13 or later. Graphics go through MoltenVK; if the game reports no Vulkan device, install the Vulkan SDK for macOS.
