# The journal's objectives: what the player is trying to do, without saying how.
#
# The original game shipped no journal. This is the port's own, and its whole reason for
# existing is that a 1999 adventure game will let a player wander for an hour with no idea
# what it wants from them. Plan/03 section 3 asks for an interface that is easier than the
# original's; this is the part of that which is about knowing where you are in the story.
#
# THE RULE FOR TITLES: say what, never how. "Get into the locked rooms" is an objective.
# "Unlock the dumbwaiters from the hallway while the maid is distracted" is a walkthrough
# line, and belongs behind the hint button where a player has asked for it. Several of these
# puzzles are the best things in the game and printing the answer in the journal would take
# them away from someone who never asked.
#
# FORMAT
#
#   [110A]                                  a point in the story, in the game's own code
#   title | condition | hint steps
#
#   condition   score:A,B   done when every one of those score events has been earned
#               any:A,B     done when any one of them has been
#               story       nothing to detect; done once the story has moved past this
#                           point. For the beats the game awards nothing for.
#
#   hint steps  which lines of Walkthrough.txt, counting from one within this point in
#               the story, answer "how". Revealed one at a time, only when asked.
#
# Every score name here is checked against Scores.txt and every step number against
# Walkthrough.txt, by JournalTests. An objective that can never complete is worse than no
# objective at all, so a typo has to fail a build rather than strand a player.
