# Content the game shipped with but cannot reach.
#
# Every line below re-enables something the developers wrote and recorded and then
# switched off — a commented-out action rule, a noun binding that was commented out
# rather than corrected when a model was renamed, or a model that was folded into a
# neighbouring noun and lost its own. Nothing here invents a line, a rule or an object.
# See docs/cut-content.md for the survey this table came out of, and for the credit:
# the catalogue that started it is Bonny Ploeg's.
#
# It is off unless asked for, and cumulative: --restore-cut-content applies
# [OBSERVATION]; "all" adds [PUZZLE]; "rebuilt" adds [RECONSTRUCTED], which is the only
# section that is not the developers' own data.
#
# Three operations, and each one verifies what it is about to change:
#
#   rule <FILE.NVC> <NOUN> <VERB> <CASE>
#       Uncomment the commented-out rule with exactly that noun, verb and case. If the
#       file has no such commented rule, or has more than one, nothing is changed and a
#       diagnostic says so.
#
#   bind <FILE.SIF> <MODEL> <NOUN> <TYPE> [after=<MODEL>]
#       Make a model clickable as a noun. If a commented-out binding for that model and
#       noun exists, it is uncommented in place, which keeps whatever else that line
#       said. Otherwise a new line is written immediately after the binding named by
#       after=, so that it inherits that line's section and its conditions — a room's
#       [MODELS] blocks are conditional, and a binding in the wrong one is either dead
#       or live at the wrong time.
#
#   place <FILE.SIF> <MODEL> <NOUN> <x,y,z[,heading]> after=<MODEL>
#       Put a model that did not ship with the game into a room. The model comes from
#       tools/blender/make_props.py by way of enhanced/models or a ReBarn pack; pos means
#       "stand here", so the coordinate is the surface it rests on. These are in
#       [RECONSTRUCTED] and nowhere else.
#
#   append <FILE.SIF> <SECTION> <LINE>
#       Add a line to the end of a named section. For the one thing the others cannot do:
#       bringing a whole action file into a room's scope, for rules that were never written
#       rather than merely switched off. Doing nothing when the line is already there.
#
#   noun <FILE.SIF> <MODEL> <NOUN>
#       Point an existing live binding at a different noun. Used where a model was
#       folded into a neighbouring noun: it keeps the line's type, its hidden flag and
#       its animation, and changes only what the player is clicking on. Every model this
#       is used on was checked to be sure the noun it is taken from keeps geometry of
#       its own.
#
# Nothing is written back to the player's installation. The archives are read-only; the
# edit is applied to the bytes on their way past.

[PUZZLE]

# These restore a verb that can do something, not only say something. Each was written
# and recorded, and each either introduces a verb the noun does not currently offer or
# stands in front of a live rule with a more specific case. That is how the original
# resolver works, so a restored rule here can change what an action does -- which is why
# they are a tier of their own rather than part of the set above.
#
# WATER_MARKS gains CLEAN, which no live rule offers.
rule DIN_ALL.NVC WATER_MARKS CLEAN GABE_ALL
rule DIN_ALL.NVC WATER_MARKS CLEAN GRACE_ALL

# Larry's alarm clock gains PRESS; the case is the one in which Larry is out and the

# The binocular view of the Château de Blanchefort gains ZOOM.

# Solomon's statue answering the radio.

[RECONSTRUCTED]

# Objects that were written, recorded and never modelled. Every one of these has live
# rules and its lines in the archives; what it never had was geometry. The meshes are
# built by tools/blender/make_props.py out of the game's own textures, and they are new
# art -- which is why they are a tier of their own and the last one.
#
# The coordinates were measured off the rooms: pos means "stand here", so each is the
# surface the thing rests on, and after= puts the line in the same block as a model that
# is already in the right place at the right time.

# Madeline's suitcase, on the floor of the hanging half of her wardrobe. The drawers take
# the left of it and her clothes hang at x 300-305, which leaves 18.6 units of floor before
# the body ends at 323.6 -- so the case is turned side-on, as luggage in a wardrobe is, and
# its 13.4 fits where its 22.4 would not.
#   "Madeline's suitcase."  /  "She's already unpacked."
place R29.SIF r29_madsuitcase SUITCASE_IN_CLOSET 313.5,2,257,90 after=r29_mad_dress

# The two documents from Dr Wen, on the writing desk in Howard and Stiles' room, whose

#   "He mentions three documents, but there're only two here."
place R31210A.SIF r31_wenletter LETTER_FROM_WEN 357,30.3,24 after=r31suitcase

# The crow's nest, RC2. The puzzle the Cat Hair Moustache replaced is complete in
# RC2102P.NVC and RC2_1ALL.NVC -- twenty-two rules, seven named cases, an inventory item
# with its sprites and a combine step -- and what it never had is geometry. These are the
# four objects it wants, and the lines that describe them.
#
# Eighteen of the puzzle's nineteen recordings were deleted, but their YAKs were not: each
# still carries its caption and simply names no sound. So these play as subtitles, at the
# length the animation was cut to, and a restored recording dropped into overrides/audio
# gives them their voice back without changing anything here.
#
# The chain itself needs two things the original's file cannot supply: the interface its
# WATER_INTERFACE rule is about, which was never built, and a definition for the case
# ON_NEST_FOR_10_SECONDS, which the rule names and no [LOGIC] block anywhere defines. The
# interface is now Game.WaterAiming; the case, and the three rules that hang off it, are in
# rc2_crowsnest.nvc, which this brings into the room's scope.
place RC2.SIF rc2_birdsnest BIRDS_NEST 1830,185,-3250 after=rc2_museum_door
place RC2.SIF rc2_crow CROW_AT_NEST 1830,198,-3250,20 after=rc2_museum_door
place RC2.SIF rc2_gardenhose GARDEN_HOSE 2080,45,-3256 after=rc2_museum_door
place RC2.SIF rc2_blackrug BLACK_RUG_IN_WINDOW 1990,100,-3262 after=rc2_museum_door
rule RC2_1ALL.NVC BIRDS_NEST LOOK NOT_GOT_BLACK_FIBERS
rule RC2_1ALL.NVC BLACK_RUG_IN_WINDOW LOOK GABE_ALL
rule RC2_1ALL.NVC BLACK_RUG_IN_WINDOW LOOK GRACE_ALL
rule RC2_1ALL.NVC BLACK_RUG_IN_WINDOW PICKUP GABE_ALL
rule RC2102P.NVC CROW_AT_NEST LOOK KNOW_ABOUT_BIKES
rule RC2102P.NVC GARDEN_HOSE THINK ALL
rule RC2102P.NVC BIRDS_NEST LOOK NOT_KAB_OR_NOT_SF
# Listed by the timeblock file rather than by RC2.SIF: a name in a general SIF has to say

append RC2102P.SIF ACTIONS rc2_crowsnest.nvc
